# Mini SOC Inteligente

## Objetivo

Este projeto tem como objetivo construir um laboratório de Security Operations Center (SOC) utilizando ferramentas gratuitas e de código aberto.

Durante o projeto serão implementados:

- Wazuh
- Docker
- Suricata
- N8N
- Inteligência Artificial
- Automação
- Monitoramento de Endpoints

---

## Tecnologias

- Rocky Linux 10
- Windows 11
- Wazuh
- Docker
- Git
- GitHub
